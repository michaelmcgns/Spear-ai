# Wealth-OS — Start Here

This is your operating system for building generational wealth across three stacks:
**Pinnacle (cash)**, **Spear (the asset)**, **Calisthenics & Brand (the future)**.

## How to open
Open this whole `Wealth-OS` folder as a vault in Obsidian (Open folder as vault).

## Plugins to install (Settings → Community plugins)
1. **Dataview** — powers the auto-updating dashboards.
2. **Tasks** — due dates + recurring tasks on checkboxes.
3. **Kanban** — the drag-and-drop boards in `06 Boards`.
4. (optional) **Templater** — to spin up daily/weekly notes fast.

After installing Dataview: Settings → Dataview → turn ON "Enable JavaScript Queries" and "Enable Inline Queries".

## Daily flow
1. Open **[[00 Home]]** — your command center.
2. Make today's note from **[[_templates/Daily Note]]** (copy into `04 Reviews/Daily`).
3. Work the blocks. Log calls in `01 Pinnacle/Call Logs`.
4. End of week: **[[_templates/Weekly Review]]** into `04 Reviews/Weekly`.

## The rule
Create > consume. Cash funds the mission. Spear builds the empire. Be the man before Italy.
